# tintora-site

The public pages for the Kulora app.

| Page | URL |
|---|---|
| About the app | https://jqdevAM.github.io/tintora-site/ |
| Privacy policy | https://jqdevAM.github.io/tintora-site/privacy/ |

Published with GitHub Pages: Settings → Pages → Deploy from a branch →
`main`, folder `/` (root).

The pages are the copy kept in the app's own repository, in `site/`.
**Change them there and copy them here**, so the policy and the behaviour it
describes stay together — every sentence in it is a claim about what the app
stores, what leaves the device, and what it asks the device for.
